# Epic Battles Online — Minimum Installation Test

The current release contains **Street Fighter**, **Tekken**, and **Tekken Promos**.

The package is built only by OCTGN's native `o8build` validator and packager.
Install/update feed: `https://www.myget.org/F/epic-battles-online/api/v2`

Version 0.3.1.1 adds the complete **119-card Street Fighter core set**, hides the internal ImageFile property, and refreshes the downloader catalog without using a stale cached manifest. The **Epic Battles Image Downloader** supports all 296 published images through the same checksum-verified manifest.
