# Epic Battles Online — Minimum Installation Test

The current release contains **Marvel Vs Capcom**, **Street Fighter 2**, **Mortal Kombat Round 1**, **Mortal Kombat Premiere**, **Street Fighter**, **Tekken**, and **Tekken Promos**.

The package is built only by OCTGN's native `o8build` validator and packager.
Install/update feed: `https://www.myget.org/F/epic-battles-online/api/v2`

Version 0.7.0.0 adds the **85-card Marvel Vs Capcom fan set** from the corrected 1.04 card data. The **Epic Battles Image Downloader** serves its 66 currently supported card images and supports 605 published images overall through the checksum-verified manifest. Street Fighter 2 remains a 39-card set with EX cards excluded.
