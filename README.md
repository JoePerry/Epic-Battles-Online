# Epic Battles Online — Minimum Installation Test

The current release contains **Street Fighter 2**, **Mortal Kombat Round 1**, **Mortal Kombat Premiere**, **Street Fighter**, **Tekken**, and **Tekken Promos**.

The package is built only by OCTGN's native `o8build` validator and packager.
Install/update feed: `https://www.myget.org/F/epic-battles-online/api/v2`

Version 0.6.0.0 adds the **55-card Street Fighter 2 fan set**. The **Epic Battles Image Downloader** currently serves its 34 finished card images and supports 534 published images overall through the same checksum-verified manifest. Additional Street Fighter 2 images can be added later without changing card IDs.
