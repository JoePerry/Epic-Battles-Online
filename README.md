# Epic Battles Online — Minimum Installation Test

The current release contains **Tekken** and **Tekken Promos**.

The package is built only by OCTGN's native `o8build` validator and packager.
Install/update feed: `https://www.myget.org/F/epic-battles-online/api/v2`

Version 0.2.0.0 adds the complete **171-card Tekken set** to the six-card Tekken Promos test set. The **Epic Battles Image Downloader** supports all 177 images through the same checksum-verified manifest.
