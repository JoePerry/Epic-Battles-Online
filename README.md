# Epic Battles Online — Minimum Installation Test

This clean test branch contains exactly one set: **Tekken Promos**.

The package is built only by OCTGN's native `o8build` validator and packager.
Install/update feed: `https://www.myget.org/F/epic-battles-online/api/v2`

Version 0.1.1.0 adds the **Epic Battles Image Downloader** for all six cards in Tekken Promos. Images remain outside the game package and are downloaded from this repository using a checksum-verified manifest.
